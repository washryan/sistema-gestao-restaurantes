# Roteiro curto de apresentacao

## Abertura

Este e um sistema full stack para gestao de restaurante com login, dashboard, pedidos, cardapio, estoque e graficos em tempo real.

## O que eu destacaria

1. O frontend foi separado do backend para deixar a arquitetura mais clara.
2. A autenticacao usa JWT e protege as rotas privadas.
3. O dashboard consome dados reais do backend e mostra pedidos, estoque e analytics.
4. O WebSocket atualiza os pedidos em tempo real.
5. O deploy foi pensado para Vercel no frontend e Render no backend com PostgreSQL.

## Fechamento

O objetivo deste projeto e demonstrar dominio de arquitetura, integracao entre camadas, deploy profissional e capacidade de evoluir um prototipo para algo pronto para producao.
